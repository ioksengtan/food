# 菜單筆記:南洋風個人套餐

日期:2026-10-01
來源:某餐廳「個人餐」菜單照片 + 實際餐點拍照(含香米飯、蔬菜,每份240元)

## 菜單摘要

個人餐共三款選擇,皆附香米飯與蔬菜:

- **A) 甜酸雞飯**——鮮檸檬、梅子醬、蔬果醋、番茄醬、糖調製的特製酸甜醬汁
- **B) 肉骨茶飯**——數十種中藥材及辛香料慢火燉煮八小時的前蹄膀肉骨茶(湯)
- **C) 椰香奶油雞飯**——辣椒、南薑、黃薑、香茅等新鮮材料特調的醬膽辣醬

可加60元升級飲品(羅漢果+紅棗+蜜棗+桂圓+香蘭 All in One)。

## 實拍餐點(對應 C 款)

椰香奶油雞飯一份:咖哩葉點綴的奶油咖哩炸雞、白飯、炒油麥菜(撒油蔥酥)、燙花椰菜、涼拌高麗菜絲、太陽蛋。是南洋娘惹風味的咖哩雞,帶黃薑與南薑香氣,醬汁濃郁偏奶香。

## 家常複刻作法(合理推測版)

⚠️ 以下為依菜名與南洋/娘惹料理常見技法反推的複刻做法,並非原店配方,比例可依口味調整。

**A) 甜酸雞**
- 食材:雞腿肉或雞翅300g(先炸至金黃)、番茄醬3大匙、梅子醬1大匙、檸檬汁1大匙、白醋1大匙、糖2大匙、洋蔥丁與甜椒丁各適量
- 作法:
  1. 雞肉醃鹽、太白粉,炸至外酥內熟備用。
  2. 洋蔥、甜椒丁炒香,加番茄醬、梅子醬、檸檬汁、白醋、糖炒勻成醬汁,煮至微稠。
  3. 放入炸雞拌裹醬汁即完成。

**B) 肉骨茶**
- 食材:豬肋排或蹄膀500g、蒜頭1整顆(不剝皮)、肉骨茶藥材包1包(市售,含當歸、川芎、肉桂、丁香等)、醬油2大匙、白胡椒粒1大匙、水1500ml
- 作法:
  1. 排骨汆燙去血水。
  2. 蒜頭、藥材包、排骨、醬油、白胡椒粒加水,大火煮滾後轉小火燉1.5–2小時。
  3. 起鍋前試鹹淡補鹽,可加油條或豆卜一起燉煮增添口感。

**C) 椰香奶油雞**
- 食材:雞翅或雞腿塊400g(先炸或煎至上色)、黃薑粉1小匙、南薑末1大匙、香茅1支(拍扁切段)、紅蔥頭與蒜頭各3瓣(打成香料糊)、辣椒適量、椰漿200ml、淡奶或鮮奶油50ml、咖哩葉一把、油適量
- 作法:
  1. 紅蔥頭、蒜頭、南薑、香茅、辣椒打成香料糊,下油小火炒香至出油。
  2. 加黃薑粉炒勻,放入炸好的雞塊拌炒裹上香料。
  3. 倒入椰漿,小火燉煮10–15分鐘至醬汁濃稠。
  4. 加淡奶或鮮奶油增加奶香,起鍋前放咖哩葉拌炒出香氣即完成。

**配菜:炒油麥菜(油蔥酥)**
- 食材:油麥菜1把、蒜末1小匙、油蔥酥1大匙、蠔油1小匙
- 作法:蒜末爆香,大火快炒油麥菜至軟身,加蠔油調味,起鍋前撒油蔥酥。

**配菜:涼拌高麗菜絲**
- 食材:高麗菜絲200g、紅蘿蔔絲少許、白醋1大匙、糖1小匙、鹽少許
- 作法:高麗菜絲加鹽抓醃出水、擠乾,拌入紅蘿蔔絲、白醋、糖調味冷藏即可。

**配菜:太陽蛋**
- 食材:雞蛋1顆、油適量
- 作法:中大火熱油,打入雞蛋,煎至蛋白邊緣焦酥、蛋黃半熟即可(影片中為兩面稍煎的台式煎法)。
