# 菜單筆記:Pastrami(五香燻肉)

日期:2026-10-01
來源:Google 搜尋摘要畫面(內容為自行整理歸納,非逐字引用)

## 背景摘要

Pastrami 起源於東歐猶太社區,後來在紐約熟食店發揚光大,是一種經典的香料醃燻牛肉。傳統做法大致分三階段:濕醃入味、表面裹料、低溫慢燻後再蒸煮至軟嫩。

## 傳統製程摘要(自行整理)

1. **濕醃**:牛胸肉浸泡在含粗鹽、糖、粉紅醃漬鹽(亞硝酸鹽,主要作用是定色與抑菌)與綜合香料的鹵水中,冷藏醃漬約一週。
2. **裹料**:洗去表面多餘鹽分並風乾後,抹上黃芥末增加附著力,再厚敷大量粗磨黑胡椒與芫荽籽。
3. **低溫慢燻與蒸煮**:先以木炭與果木低溫慢燻至表面上色,再加熱蒸煮至肉質軟嫩、膠原蛋白轉化為明膠。
4. **常見吃法**:切片夾入黑麥麵包做成經典三明治,搭配黃芥末等。

## 家常簡化複刻版(合理推測,無專業燻爐可用方案)

⚠️ 以下為依傳統製程原理反推的家用簡化做法,並非特定店家配方,比例可依口味調整。多數家庭沒有專業燻爐,改用烤箱分段烤+蒸的方式模擬質地。

**食材**
- 牛胸肉(brisket)1.5–2kg
- 醃鹵水:水2L、粗鹽150g、糖100g、粉紅醃漬鹽(Prague powder #1)10g(可選,主要影響安全保色,省略則須盡快食用、不可久放)、黑胡椒粒、芫荽籽、丁香、月桂葉、蒜瓣適量
- 裹料:黃芥末醬適量、現磨黑胡椒2大匙、芫荽籽碎2大匙

**作法**
1. 鹵水材料加水煮滾溶解鹽糖,放涼後完全浸泡牛胸肉,冷藏醃漬5–7天,期間每天翻面。
2. 取出醃好的肉,沖水洗去表面鹽分,風乾至表面微乾(室溫1–2小時或冷藏一夜)。
3. 表面薄塗黃芥末醬,均勻厚敷黑胡椒粗粒與芫荽籽碎。
4. 增香上色(家用簡化):有燻烤爐可用果木低溫(約110°C)燻2–3小時;沒有的話用烤箱低溫(120°C)烤約2小時上色,想增加煙燻味可用鑄鐵鍋鋪茶葉/木屑做簡易室內煙燻。
5. 蒸煮至軟嫩:將上色後的肉移入蒸鍋,或烤盤加水加蓋以150°C續烤/蒸2–3小時,至肉質可輕鬆用叉子撕開。
6. 取出稍放涼,逆紋切薄片。

**品嚐方式**
- 經典三明治:黑麥麵包夾厚切pastrami,搭配黃芥末醬與酸黃瓜
- 做成 Reuben 三明治:加酸菜(sauerkraut)、瑞士起司、千島醬,壓烤至起司融化
